Responsea whole new profile.md replaces the stored copy
  • Clicks on expertise, cards, question pills and roles edit profile.md in the browser. No server call.
  • Every API call also writes one llm_usage row to Supabase: tokens and cost only, no content.
  • Every call: adaptive thinking, structured JSON output, no web tools. claude-opus-5-5 for cards, preferences and discovery; claude-sonnet-5-5 for searches (MODEL_BY_STEP). All go through llm.ts.

Where the ground truth is

  • Your words: pasted text, notes, pill answers, clicks. Every field and role must cite one of your cards.
  • Reference collection: hand-curated YAML, mirrored to Supabase. Explains fields and roles; only source of links. Never powers a search.
  • The model's own knowledge: fields or roles the collection lacks. Kept with no source link.

Not shown here

  • In the code with no UI path: reviseQueries (step revise, rating a search; scripts only, technical-plan D51), exploreField (web drill-down), interpretAnswer, reviseCards
  • Profile drawer: a readable summary; export and import behind "Export". No API call
  • "Start over" in the header: clears the browser copy. No API call
